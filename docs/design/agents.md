# 외부 Agent

외부 Agent는 OpenAI 호환 `chat/completions` 엔드포인트를 가리키는 registry 항목이다.
관리자는 이름, URL, 설명과 요청 헤더를 등록한다. 저장된 설명은 동적 검색과 모델의
위임 대상 안내에 사용된다. Project의 `subagentList`에서 `type: "remote"`로 연결하면
런타임이 해당 Agent를 도구로 제공한다.

등록 및 수정 시 URL에 자격 증명이 포함되지 않았는지 확인하고, 외부 URL 정책으로
대상 주소를 검사한다. 디스패치 직전에도 같은 정책을 확인한다. 헤더 값은 Agent 이름에
묶인 문맥으로 암호화해 저장하고, 콘솔 조회에는 마스크만 반환한다. URL이 바뀌면 기존
헤더를 새 주소로 보내지 않으며 새로 입력한 값만 저장한다.

위임은 사용자 요청과 필요한 대화 문맥을 하나의 메시지로 보내고, 원격 응답의 텍스트를
부모 Agent에 돌려준다. 호출은 런의 취소 신호와 120초 전송 한도를 따르고, 응답 본문은
2MB까지만 읽는다. HTTP 오류나 응답 형식 오류는 실패한 도구 결과로 전달한다.
원격 Agent의 `Test message`는 같은 주소·헤더로 짧은 확인 요청을 보내며 별도
실행 기록을 만들지 않는다.
